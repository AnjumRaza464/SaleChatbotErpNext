# Chatbot – Tab-wise exact questions

Yeh sawal jaise hain waise hi chatbot mein type karein (ya mic se bolein).
Jahan "Ali Traders", "Main Store", "Sugar 1kg", "Ahmed Khan" likha hai wahan apna customer/warehouse/item/employee ka naam likhein.
Har sawal Roman Urdu mein bhi poocha ja sakta hai (e.g. "Aaj ki sale kitni hui?").
Kisi bhi sawal ke aakhir mein "in detail" lagane se lambi reply milti hai.
